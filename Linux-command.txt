54. File Management:
Each file has three types of permissions: read (r), write (w), execute (x) and And three classes of users: owner (u), group (g), others (o)
    a. chmod : The chmod (Change Mode) command is used to change the permissions of files and directories.
    chmod +x filename --> (add execute permission for all users)
    chmod -x filename --> (remove execute permission for all users)
    chmod +r filename --> (add read permission for all users)
    chmod -r filename --> (remove read permission for all users)
    chmod +w filename --> (add write permission for all users)
    chmod -w filename --> (remove write permission for all users)
    chmod u+x filename --> (add execute permission for the file owner)

    chmod o-r filename --> (remove read permission for others)
    chmod 644 filename --> (set permissions to rw-r--r--)
    chmod 755 filename --> (set permissions to rwxr-xr-x)

    b. chown : The chown (Change Owner) command is used to change the ownership of files and directories.

    chown -R username directory_name --> (recursively change the owner of a directory and its contents)
    chown -R username:group_name directory_name --> (recursively change the owner and group of a directory and its contents)

60. Input and Output Redirection : Linux provides input and output redirection operators to control where command input comes from and where output is sent.
command > file --> (redirect standard output to a file, overwriting the file if it exists)
command >> file --> (append standard output to the end of a file)
command < file --> (use a file as standard input for a command) , ex - sort < sample.txt
command1 | command2 --> (send the output of command1 as the input to command2)
command > success.log 2> error.log --> (redirect successful output and error output to separate files)
command >> success.log 2>> error.log --> (append successful output and error output to separate files)
command > /dev/null --> (discard successful output)
command 2> /dev/null --> (discard error output)
command > /dev/null 2>&1 --> (discard both successful output and error output)
command &> output.log --> (redirect both successful output and error output to the same file)
